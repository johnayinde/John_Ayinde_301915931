# Portfolio 1 - Database Design and Modelling

## Files

- `John_Ayinde_301915931_P1_Design.md`: organisation, users, data and operations.
- `John_Ayinde_301915931_P1_ERDiagram.mmd`: editable Mermaid ER diagram source.
- `John_Ayinde_301915931_P1_Schema.sql`: PostgreSQL tables, primary keys, foreign keys, checks and indexes.
- `John_Ayinde_301915931_P1_SampleData.sql`: fictional sample records.
- `John_Ayinde_301915931_P1_ConstraintTests.sql`: queries to confirm that the model works.
- `John_Ayinde_301915931_P1_Normalisation.md`: 1NF, 2NF and 3NF explanation.

## Implementation steps

1. Create a PostgreSQL database named `landmark_hotel_db`.
2. Run `John_Ayinde_301915931_P1_Schema.sql`.
3. Run `John_Ayinde_301915931_P1_SampleData.sql`.
4. Run each query in `John_Ayinde_301915931_P1_ConstraintTests.sql` and check the result.
5. Capture screenshots of the SQL execution and results in a local `evidence/` folder.
6. Update this README with your PostgreSQL version, the date you tested the scripts, any changes you made, and a short explanation of what you observed.
